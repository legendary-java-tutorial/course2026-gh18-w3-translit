# translit

Игра загадывает число, а вы угадываете: на каждую догадку она отвечает «бери выше», «бери ниже» или «в точку!». Тема — космос: сколько звёзд я загадал? Для тех, кому нужна минутная передышка между делами.

**Сыграть в браузере:** https://legendary-java-tutorial.github.io/course2026-gh18-guess-number/

![Игра в браузере: выбор режима и первая догадка](images/game.png)

## Как запустить

Нужен Node.js 24.12 или новее.

```
npm install
npm start
npm test
```

## Режимы

| Режим | Числа | Для чего |
|---|---|---|
| classic | 1–100 | спокойная партия |
| quick | 1–10 | пара догадок, пока закипает чайник |
